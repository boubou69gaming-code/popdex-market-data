# PopDex Market Data

Ce dépôt héberge les cotations de marché de référence du rétrogaming et du jeu vidéo (PriceCharting, eBay) pour l'application **PopDex**.

## 📊 Données disponibles
* **Matériel & Consoles** : 46 consoles physiques et leurs 194 variantes (Loose, CIB, Mint/Neuf).
* **Jeux** : 50 477 titres de catalogue individuellement valorisés.

## 🔄 Synchronisation Automatique
* **Fréquence** : Chaque lundi à 03:00 UTC via GitHub Actions (`.github/workflows/update_prices.yml`).
* **Lien Raw public** : `https://raw.githubusercontent.com/boubou69gaming-code/popdex-market-data/main/prices.json`

## 🔒 Sécurité & Intégrité
* Dépôt public en **lecture seule** pour les clients mobiles.
* Droits d'écriture strictement restreints au propriétaire (`boubou69gaming-code`) et à la clé d'automatisation GitHub Actions.
